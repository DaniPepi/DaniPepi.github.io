Travel Advantage.

Prepara i collegamenti da mostrare nella finestra Viaggi. La pubblicazione richiede l’accesso al tuo account GitHub con permessi sul repository. Nessuna password viene richiesta o salvata su questo sito.

Le modifiche preparate qui non sono pubblicate finché non le confermi nell’editor GitHub.

Caricamento dei collegamenti pubblicati…

    Apri editor GitHub
    1. Copia la configurazione.
    2. Apri l’editor GitHub e accedi con il tuo account.
    3. Sostituisci il contenuto del file con la configurazione copiata.
    4. Conferma con “Commit changes”. GitHub pubblicherà l’aggiornamento.

    Questa pagina può essere letta da chiunque, ma solo gli utenti autorizzati sul repository possono pubblicare modifiche. I link inseriti saranno pubblici: non inserire token privati o credenziali.

    Foto e biografie del team

    Carica le fotografie nella cartella assets del sito, poi aggiungi nel file team.json nome, ruolo, biografia e percorso della foto. Le modifiche vengono pubblicate dopo il commit su GitHub.

    Modifica i profili su GitHub

    Campi per ciascun membro: name, role, bio, photo. Esempio percorso: assets/nome-membro.jpg.
